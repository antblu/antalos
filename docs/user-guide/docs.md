This site is the handbook for using, understanding, and operating antalos. Each application has three companion guides: a practical user introduction, an explanation of its backend, and an administrator's deployment runbook. The pages describe repository configuration; live health must be inspected separately.

## Access and audience

For this installation, use [docs.antblu.net](https://docs.antblu.net). If you use another antalos installation, open the address supplied by its administrator. Ask for the account or role you need before starting.

## Your first workflow

1. Choose a service from the [Service directory](/user-guide/services/).
2. Read its **Use** guide to understand the workflow and first task.
3. For infrastructure questions, read its **Architecture** guide.
4. For deployment and recovery, read its **Operate** guide.

## Learn more

Use the **Official documentation** links in each service guide for detailed product instructions. They explain the product's features; this handbook explains the antalos installation. Features shown in upstream documentation may depend on the version or options your administrator enabled.
